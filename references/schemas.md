# Schemas

Use JSONL for intermediate artifacts. Each line must be one valid JSON object.

## derivation_index.json

Generated by `scripts/index_remote_repo.py` when scanning a GitHub/GitLab URL
without cloning the repository locally.

```json
{
  "schema_version": "derivation_index.v1",
  "generated_at": "2026-07-08T00:00:00+00:00",
  "repository": {
    "url": "https://github.com/org/repo",
    "provider": "github",
    "host": "github.com",
    "project_path": "org/repo",
    "branch": "main"
  },
  "summary": {
    "tree_file_count": 1200,
    "indexed_file_count": 180,
    "candidate_file_count": 12,
    "candidate_variable_count": 240,
    "chunked_file_count": 12,
    "chunk_count": 36,
    "dependency_chunked_file_count": 5
  },
  "files": [
    {
      "path": "features/loan_features.py",
      "language": "python",
      "size": 12400,
      "sha": "abc123",
      "candidate_score": 0.92,
      "is_candidate_feature_file": true,
      "included_in_chunks": true,
      "chunk_include_reasons": ["selected candidate file"],
      "candidate_variables": ["loan_cnt_30d", "loan_amt_sum_30d"],
      "signals": [
        {
          "type": "dataframe_assignment",
          "line": 42,
          "value": "loan_cnt_30d",
          "snippet": "df[\"loan_cnt_30d\"] = ..."
        }
      ],
      "reasons": [
        "found 2 candidate variable names",
        "contains aggregation signal",
        "contains time_window signal"
      ],
      "symbols": [
        {
          "name": "build_loan_features",
          "type": "function",
          "line_start": 10,
          "line_end": 110
        }
      ]
    }
  ]
}
```

When `--include-dependencies` is enabled, dependency files can have
`is_candidate_feature_file: false` and still be chunked. Their
`chunk_include_reasons` should explain why, for example:

```json
{
  "path": "utils/date.py",
  "is_candidate_feature_file": false,
  "included_in_chunks": true,
  "chunk_include_reasons": ["import referenced by features/loan_features.py"]
}
```

## code_chunks.jsonl / remote_code_chunks.jsonl

`code_chunks.jsonl` is generated from local files by `scripts/scan_codebase.py`.
`remote_code_chunks.jsonl` is generated from remote GitHub/GitLab candidate
files by `scripts/index_remote_repo.py --chunks-out`. They share the same
schema so downstream lineage extraction can use either file.

```json
{
  "chunk_id": "relative/path.py::function::func_name::12-80",
  "file": "relative/path.py",
  "language": "python",
  "symbol_type": "function",
  "symbol_name": "func_name",
  "start_line": 12,
  "end_line": 80,
  "code": "..."
}
```

```json
  "feature_template": "bank_txn_balance_anomaly_days_{w}d",
  "feature_is_template": false,

  "evidence_snippet": "out[f\"bank_txn_balance_anomaly_days_{w}d\"] = ..."

```

## lineage_facts.jsonl

```json
{
  "feature": "bank_txn_balance_anomaly_days_14d",
  "source_file": "input/txn_eod.py",
  "source_module": "txn_eod",
  "source_class": "代码中未明确体现",
  "source_function": "_build_balance_series_features",
  "input_fields": ["balance", "balance_date"],
  "filter_conditions": ["balance_date within window"],
  "groupby_keys": [],
  "aggregation_method": ["sum"],
  "calculation_expression": "sum(is_balance_anomaly)",
  "time_window": "14",
  "time_window_unit": "d",
  "upstream_features": [],
  "business_conditions": ["代码中未明确体现"],
  "evidence_chunk_id": "input/txn_eod.py::function::_build_balance_series_features::120-230",
  "evidence_snippet": "out[f\"bank_txn_balance_anomaly_days_{w}d\"] = int(slc['is_balance_anomaly'].sum())",
  "confidence_level": "high",
  "confidence_reason": "变量赋值和计算表达式在同一代码块中明确出现"
}
```

Required fields for `lineage_facts.jsonl`:

- `feature`
- `source_file`
- `source_module`
- `source_function`
- `input_fields`
- `filter_conditions`
- `aggregation_method`
- `calculation_expression`
- `time_window`
- `time_window_unit`
- `evidence_chunk_id`
- `evidence_snippet`
- `confidence_level`
- `confidence_reason`

Use `代码中未明确体现` or `根据变量名推测` instead of empty strings when information is uncertain.
